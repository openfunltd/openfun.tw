ABOUT 關於歐噴

「取之於開放，用之於開放：讓技術轉化為社會進步的有趣動力。」

歐噴（OpenFun）的名字源自於對「開放」的拆解 —— 「開」與「放」，即是 Open 與 Fun。我們深信實踐開放文化（Open Culture）的過程不僅充滿挑戰，更具備改變社會的樂趣。我們召集志同道合的夥伴，將心中的創意與技術實作轉化為程式碼，不僅持續探索最新科技，更致力於將技術落實為應用，與世界共享成果。

創辦人 Ronny 作為 g0v 零時政府的長期參與者，並發起了「台灣公司資料」、「公司關係圖」、「開放政府標案」、「開放政治獻金」、「求職小幫手」、「新聞小幫手」、「鄉民看電視」、「國會觀察家」...等專案。這些經驗不只是黑客松的實驗，更是已穩定運作超過十年、持續服務大眾的成熟專案。在累積了深厚的資料爬蟲、地理資料處理、搜尋引擎、語音轉逐字稿及大型語言模型（LLM）等技術後，歐噴有限公司成立了。

現在，這份深耕十年的技術底蘊，轉化為解決公共問題的實體產品。歐噴開發了 OpenBudget 政府預算查詢，將繁雜難懂的預算書轉化為視覺化、可比較的結構化資料；透過 LawTrace 立法足跡，將分散在各機關的法案資訊一鍵彙整，大幅降低公眾參與立法的門檻；並推出 立法院國會頻道 AI 即時轉換逐字稿，讓國會討論能以最快的速度轉化為可搜尋的文字紀錄。

歐噴專注於「開放政府」與「資料應用」兩大核心，致力於為客戶與公民社會提供長久穩定、具備實質影響力的數位工具，讓複雜的治理變得簡單、透明且易於參與。

OpenBudget 政府預算查詢
Budget

告別在數百個 PDF 與零散網頁中來回翻找的痛苦。長年以來，政府依法公開預算與決算書，卻多以難以使用的格式呈現，讓想理解政府如何花錢的人，必須把大量時間花在整理資料，而非分析與監督。

預算查詢平台運用歐噴十多年政府資料爬蟲與清理經驗，將分散於各機關、各縣市、各年度的預決算書，整理為可搜尋、可比較的結構化資料庫，不必再下載成千上萬頁文件，就能快速掌握預算配置與變化。

理解預算不再只是少數專業者的工作。透過直覺的查詢與比較介面，讓公民也能輕鬆參與預算討論，看懂政府把錢花到哪裡。

link https://budget.openfun.app
Lawtrace 立法足跡
legislature

我們透過研究發現，即使是倡議團體、媒體記者、立委助理、事實查核團體等經常查詢立法院資料的專業工作者，在檢索法案資料時，依舊需要耗費大量時間，跨越多個網站與開啟一長串的分頁，或是埋首在數百頁的文件中才能找到所需資訊。

對於不常使用立法院網站的一般民眾來說，想查法案資料更是困難重重。資料難以取得，背離立法院公開資料的初衷，公民因此難以關注修法進程，民主精神難以落實。

LawTrace 將資訊彙整在一處。找尋資料時，我們可以少開幾個分頁、更有效率，查找的更愉快！

link https://lawtrace.tw
台灣公司資料
COMPANY g0v

2013年1月開始寫爬蟲，耗費三個月時間抓取完 200 萬家公司資料，之後建立起每日自動更新機制，持續更新至今，為台灣最完整公開公司資料，並且有使用 API 供人使用，衍生出像台灣公司關係圖、手開發票小幫手等功能，也有 Simpany 及許多會計事務所串接使用。資料庫採用 MySQL + ElasticSearch。

link https://company-graph.g0v.ronny.tw
開放立法院
Legislature g0v

立法院每年產生一萬多則議案，每週召開十數場會議，每月公報產生數萬字文字的會議紀錄，原始格式從 Word、網頁、PDF 不等並分散在各種來源，本公司利用多隻爬蟲進行自動化資料清理匯入，並製成 API 以及相關服務，幫助公民監督國會聯盟自動化立委評鑑及法案對照表瀏覽，以及幫助報導者產製「你家立委4年來為哪些議題發聲？」報導。

link https://openfunltd.github.io/law-diff/
立法院國會頻道AI即時轉換逐字稿
